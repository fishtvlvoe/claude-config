# Skill 分工定義

## 設計類

| Skill | 輸入 → 輸出 |
|-------|-----------|
| `cinematic-design` | 導演/情緒 → 電影化版型 |
| `design-style` | 品牌名/風格詞 → 品牌規範 |
| `dp` | 設計疑問/決策 → 哲學核對盲點 |
| `ui-ux-pro-max` | 產品類型+風格+技術棧 → 可落地 UI 系統 |

## 商業驗證類

| Skill | 輸入 → 輸出 |
|-------|-----------|
| `validate-idea` | 客群痛點假設 → 可行性判決 |
| `processize` | 點子+人力限制 → 可收費手動 SOP |
| `mvp` | 已驗證需求 → 最小功能清單 |
| `minimalist-review` | 任一策略 → 八原則風險檢查 |

## 決策樹

設計體驗：要敘事感 → `cinematic-design`；品牌對齊 → `design-style`；邏輯校準 → `dp`；快速產規格 → `ui-ux-pro-max`

商業驗證：先 `validate-idea` → 能收費走 `processize` → 流程穩定再 `mvp` → 重大決策前補 `minimalist-review`
